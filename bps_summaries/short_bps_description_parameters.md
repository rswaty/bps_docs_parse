# Short BpS Description Parameters

Parameters for the Conservation Gateway pilot. Write one short description for each BpS name.

## Purpose

These descriptions help a user narrow the BpS returned by a search, beyond vegetation type, map zone, and fire regime group. Some of that information will repeat what those filters already show. That repetition is useful. Users need different amounts of help.

This is a coarse search aid. The description does not need to isolate one BpS.

This is a pilot, not the final version. Other uses for a short BpS description may change what we include later. Those uses are still to be determined and should not hold up testing the process.

## Unit

One description per BpS name. Many names are modeled in more than one map zone. Map zone is already a search filter, so the description should cover the shared system. Where the source describes a broad type and then a narrower mapped portion, use the narrower portion.

## Length

500 words or less.

## What to include

Write in this order.

1. **General geography.** States or a familiar region. Use the range of this system.
2. **Landscape position, when it sets the system apart.** Examples: flatwoods, chutes, potholes, terraces, lake plains, dunes, floodplains. Skip a generic “upland” and skip soil lists.
3. **Vegetation pattern.** How the landscape is composed. Either a mosaic of life forms, such as shrubs, saplings, and mature trees, or one life form through all succession stages, such as trees dominating every stage. Use plain language. Succession-class codes, cover percents, and Early/Mid/Late labels stay in the source models.
4. **Key disturbance.** The main natural disturbance, plus at most two secondary ones. A short clause on what that disturbance maintains is enough. Fire regime group already carries the frequency class, so leave out return intervals and severity percentages.
5. **Three to five key species, by common name.** Choose characteristic species a user would recognize. Mix life forms when the system is a mix of trees, shrubs, and grasses. Skip rare species and species that occur only on the edge of the system.

## What to leave out

Map zone numbers, ecoregion codes, acreages, soil catalogs, climate figures, rare plants, citations, adjacency notes, and model disputes.

## Example

Eastern Great Plains Tallgrass Aspen Parkland:

Found primarily in northwestern Minnesota and southern Canada, on the level plain of Glacial Lake Agassiz. Historically the landscape was a mosaic of tallgrass prairie, wet and brush prairie, shrubs, and aspen-oak woodland. Frequent fire is the main disturbance, with wind and grazing by native herbivores also important. Characteristic plants are aspen, bur oak, willow, hazel, and big bluestem.
